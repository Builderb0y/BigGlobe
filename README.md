A worldgen mod for Minecraft. Download it from [Modrinth](https://modrinth.com/mod/big-globe) or [GitHub releases](https://github.com/Builderb0y/BigGlobe/releases).

Hall of fame:

This project used to be very difficult to compile.
* I have many dependencies that aren't listed in build.gradle.
* My source sets used to be full of symbolic links, though I flattened everything when porting to MC 26.1.
* javac used to NPE when trying to compile my code, though that got fixed when I updated something.

I made it a challenge at one point that anyone who can compile this project unassisted gets to be mentioned here. This task is no longer as challenging as it used to be, so this reward has been revoked now. Nevertheless, here are all the cool people who managed to beat that old challenge back when it was still challenging:
